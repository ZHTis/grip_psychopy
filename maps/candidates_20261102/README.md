# 10 张候选地图

本批用于审阅，尚未接入当前任务。每张保留原图 100 个障碍、44 个顶部和 56 个底部障碍、宽高组合及相邻中心间距的分布；独立随机重排间距和障碍组合。首个障碍中心 X=100，末个 X=9670，任务计算终点 X=9729，玩家起点 X=20。随机种子及原图 SHA256 见 manifest.json。

复现：通过项目运行环境执行 tools/generate_candidate_maps.py；图形脚本为 tools/plot_candidate_maps.py。原 config 的地图设置未变。候选 CSV 经当前 load_map 读取校验，10 张互不相同、终点一致、矩形不出世界边界；未据此宣称动力学难度等效或已完成真人通关验证。

当前前进速度 30 单位/秒、反馈上限 45 秒，玩家中心最多前进至 X=1370；碰撞可能更早结束。Excel 同时展示全图及前段放大图，并保存可筛选精确中心坐标、尺寸、公式边界。图为静态快照，编辑坐标后需重新绘图。

示例 session 排序为无放回随机排列，仅展示，尚未接入任务；未来接入时每 session 记录顺序、种子与每轮 map ID。
